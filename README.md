# Among vs Zombies

Juego 2D hecho en Godot, basado en el tutorial oficial "Your first 2D game" de Godot Docs, con mecánicas extra agregadas: sistema de disparo (raycast direccional), munición limitada que se recarga cada 10 puntos, y música de fondo.

## Cómo correrlo
- **Opción 1:** Descarga el ejecutable en `/build` y corre `AmongVsZombies.exe`.
- **Opción 2:** Abre el proyecto en Godot 4.7+ y presiona Play.

## Controles
- Movimiento: flechas direccionales / WASD
- Disparar: Espacio

## Mecánicas extra implementadas
- Sistema de disparo con raycast y munición limitada
- Recarga automática de balas cada 10 puntos de score
- Música de fondo
- Sprites personalizados del personaje
